# AFK Admin Panel - V6 Final

**AFK Admin Panel - V6 Final** is a professional Lua script designed for Roblox, featuring a clean blue and white UI, real spam functionality, and log protection.

## ✨ Features
- 🛡️ **Log Protection:** Automatically scans and destroys admin/log-related GUIs to maintain privacy.
- 📢 **Real Spam Mode:** Automates command execution by sending them directly to the game chat (supports both Legacy Chat and TextChatService).
- 📋 **Command Presets:** Includes presets for "Moderator + Admin", "Head Admin", and "Ghamid" versions.
- ⌨️ **Custom Commands:** Add or remove commands dynamically through the settings panel.
- 🎨 **Modern UI:** Draggable, clean blue and white interface.

## 🚀 How to Use
1. Copy the content of `AFK_V6_Final.lua`.
2. Execute it using your preferred Lua executor in a Roblox environment.
3. Use the toggle button to open/close the panel.
